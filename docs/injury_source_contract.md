# Injury adapter contract

The program fetches the public Roegele TJ List and UCL InternalBrace tabs. TJ List must include `Player` and `TJ Surgery Date`; MLBAM linkage uses `mlbamid` when present. Optional columns include `fgid`, `Team`, `Level`, `Position`, `Throws`, `Age`, `Return Date (same level)`, `Recovery Time (months)` and `Surgeon(s)`. A donations row may precede the true Player header. The InternalBrace tab uses `UCL primary repair with internal brace construction Date`, generally has no IDs. Legacy exact-name crosswalks are flagged for review; further reconciliation uses Chadwick identifiers, unique register names with biographical/career corroboration, and MLB metadata. Ambiguous cases remain unmatched.

The sheet ID is configurable. If hosting or column names change, adapt only `src/ingest_injuries.py` and preserve the raw source/cache. An inaccessible or malformed source is logged as failed; existing evidence is retained for audit but the run does not silently claim known negative labels. There is no mandatory manual-upload path. A future replacement adapter must emit the `injuries` schema in `sql/schema.sql`, including provenance, date precision, nullable MLBAM identity and unknown onset fields.

Known source caveats: day 1 may denote unknown day; January 1 may denote unknown month/day; an asterisk in Throws indicates a non-throwing-arm operation. Treat day-1 cases conservatively because CSV cannot distinguish an actual first-of-month date from the documented placeholder. Exact return dates are retained for audit only. Surgery-level individual reference links are not supplied in the fetched structured columns; source_reference remains NULL and source_url points to the workbook.

`known_onset_date` and the episode `label_reference_date` are public evidence proxies, not biological onset. Historical builds link procedures by exact reconciled MLBAM ID to active public elbow/UCL/forearm IL episodes. An official activation breaks the inferred episode; a subsequent observed MLB appearance permits risk-set reentry. Active episodes can precede surgery by more than 180 days. Generic arm complaints and long intervals require event-level review.

The first retrieved arm-IL announcement in that episode is the reference; administrative/retroactive effective dates remain separate. First symptom, diagnosis and verified last healthy dates remain NULL without explicit evidence. Surgery-only cases retain uncertain onset and cannot create exact positive labels. The configurable 180-day preoperative uncertainty interval is a censoring rule, not an invented onset date.

`injury_events` counts episodes; `injury_event_procedures` preserves the source procedure map. Multiple procedures in one episode do not multiply event-level recall. `reports/injury_event_audit.csv` includes reference dates, evidence URLs, pre-reference appearances, positive-row counts and confidence. All positive cases still require substantive public-evidence review before interpreting the labels as an injury-onset standard.
